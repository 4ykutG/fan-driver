# Roadmap

## Before the public release

- Validate Automatic, Silent, Maximum Fan and the 90°C override on hardware.
- Confirm Fn+F7 and both GNOME/GTK OSD implementations.
- Confirm GitHub Actions are green and add an OSD screenshot.
- Choose the final project name, make the repository public and tag `v0.2.0`.

## Later

- AUR packaging.
- Translation infrastructure and English UI strings.
- KDE Plasma, Hyprland and Sway OSD testing.
- Additional models only after exact firmware validation and upstream
  `msi-ec` support.
